# Roadmap

## Near term

- Add release tags and packaged binaries
- Improve UI polish and mobile ergonomics
- Expand integration coverage beyond single-node loopback flows
- Improve transfer failure reporting and retry behavior

## Security

- Add encrypted transport or a documented TLS termination strategy
- Add stronger peer identity guarantees than short-lived pairing plus token exchange
- Tighten auditability around pair lifecycle and transfer history

## Platform support

- Clarify Linux distribution support
- Evaluate BSD and macOS compatibility paths
- Separate platform-specific discovery concerns from the core transfer logic

## Product surface

- Better peer presence indicators
- Optional transfer acceptance prompts
- Localization support for the web UI
- Clearer operational admin docs

## Contribution opportunities

Good areas for contribution:

- tests
- documentation
- UI improvements
- platform compatibility
- security hardening
