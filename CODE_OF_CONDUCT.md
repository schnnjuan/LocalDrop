# Code of Conduct

## Our standard

We want LocalDrop to be a respectful, technically rigorous, and welcoming project.

People participating in this project are expected to:

- be respectful in technical disagreement
- assume good intent while still challenging weak ideas
- focus feedback on behavior, code, and outcomes
- avoid harassment, insults, discrimination, or personal attacks
- respect different experience levels and backgrounds

## Examples of acceptable behavior

- giving clear and actionable code review feedback
- asking questions instead of making assumptions
- documenting tradeoffs honestly
- helping newcomers understand the current architecture
- acknowledging mistakes and correcting them quickly

## Examples of unacceptable behavior

- harassment, intimidation, or discriminatory language
- repeated hostile or dismissive comments
- publishing private information without permission
- derailing discussions with personal attacks
- deliberately wasting maintainer or contributor time

## Enforcement

Maintainers may remove comments, reject contributions, or restrict participation for behavior that harms the project or its contributors.

## Reporting

For conduct concerns, contact the project maintainers privately when possible. If a private channel is not available, open a minimal public issue only when needed to keep participants safe.

## Scope

This Code of Conduct applies to project spaces, including issues, pull requests, code review, and other related communication channels.
