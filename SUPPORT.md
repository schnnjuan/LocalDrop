# Support

## Where to ask for help

- Usage questions: open a GitHub issue with enough environment detail to reproduce the problem.
- Bug reports: use the bug report template.
- Feature proposals: use the feature request template.
- Security concerns: follow [SECURITY.md](./SECURITY.md).

## What helps maintainers most

- the exact command you ran
- your operating system and package versions when relevant
- relevant logs or screenshots
- whether the issue happens on `main`
- a minimal reproduction if possible

## Scope

Support is best-effort. Clear reproduction details and focused reports will get handled faster than vague or bundled requests.
